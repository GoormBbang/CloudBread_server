# 🍽️ 열 달의 식탁

**열 달의 식탁**은 임산부가 임신 기간 동안 개인 건강정보, 임신 주차, 알레르기, 식단 히스토리를 기반으로  
🤖 AI 추천 식단과 영양 분석, 맞춤형 정보를 제공받을 수 있는 **통합 임산부 영양 관리 서비스**입니다.

 <br />

## 🎯 1. 프로젝트 목적

임산부는 임신 중 균형 잡힌 식습관이 중요하지만,  
⚠️ 주의해야 할 음식과 영양 정보가 분산되어 있어 관리가 어렵습니다.  
또한 임신성 당뇨, 고혈압 등 개인 건강 상태를 고려한  
**맞춤형 식단 관리 서비스**는 부족한 상황입니다.

본 서비스는 임산부가 자신의 임신 주차와 건강 상태에 맞는  
🥗 식단 관리와 영양 정보를 **한 곳에서 통합적으로 관리**할 수 있도록 돕는 것을 목표로 합니다.

 <br />

## ✨ 2. 주요 기능

- 👤 임신 주차·건강 정보 기반 사용자 관리
- 🤖 AI 기반 오늘의 맞춤 식단 추천
- 📸 음식 사진 업로드를 통한 영양 분석 및 식단 기록
- 💬 임산부 맞춤 상황별 챗봇 제공
- 📅 캘린더 기반 영양 분석 및 AI 피드백
- 🤰 임신 주차별 맞춤 건강 정보 제공

 <br />

## 🛠️ 3. 기술 스택

- **Frontend**: React Native  
- **Backend**: Spring Boot, FastAPI  
- **Database**: MySQL  
- **Search**: Elasticsearch  
- **AI / LLM**: LangChain, LangGraph, FAISS, OpenAI API  
- **Crawling**: Selenium, Jsoup  
- **Infra / DevOps**: Docker, NKS, NKS Pipeline  
- **Collaboration**: Git, Notion  

 <br />

## 🔄 4. 시스템 및 데이터 흐름 요약

본 서비스는 사용자 입력 데이터와 AI 분석 결과를 기반으로  
개인 맞춤형 식단 추천 및 영양 관리를 제공합니다.

- 📸 음식 사진 업로드  
  → 🤖 AI 음식명 추출  
  → 🔍 Elasticsearch 유사 음식 검색  
  → 🗂️ 식단 기록 저장
- 🧠 임신 주차, 건강 상태, 알레르기, 식단 히스토리를 종합 분석해  
  AI 맞춤 식단 및 영양 피드백 생성
- 🌐 Selenium과 Jsoup을 활용해 수집한 임신 주차별 정보를  
  사용자 임신 단계에 맞게 제공
